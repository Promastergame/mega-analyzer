Чистка ложных срабатываний по всему движку, ускоренный быстрый профиль, WASM-инфраструктура выпуска и сайт проекта — [mega-analyzer.lol](https://mega-analyzer.lol).

- Движок: быстрый профиль учитывает переключатели модулей — значения по умолчанию больше не включают обратно data-flow, crack points и поиск аномалий (быстрая триаж-оценка стала быстрее примерно на 15 секунд).
- Ложные срабатывания на чистых APK: подавлен шаблонный код `setAccessible` с пользовательскими ключевыми словами, внутренности Play Billing SDK считаются библиотечным кодом, находки нативных артефактов дедуплицируются между копиями ABI, обычные числовые литералы больше не создают «Derived Exploit Payload».
- Отчёты: баннер ограничения покрытия убран из HTML/Markdown (данные остались в `analysis.json`).
- Веб-интерфейс: iframe отчёта получил тёмный фон (белая полоса прокрутки под отчётами исчезла), приложение объявляет свою цветовую схему.
- Брендинг: favicon.ico/PNG + apple-touch-icon везде, встроенная иконка для вкладок REPORT и красная эмблема с жуком в качестве логотипа боковой панели.
- Сайт: [mega-analyzer.lol](https://mega-analyzer.lol) — в подвале боковой панели ссылка на каталог исходников mrbeast.art.
- Инфраструктура: `scripts/build_web_site.py` собирает WASM-сайт (bridge/worker/pool/memfs/GNN, цели GOOS=js) и копирует иконки; версия повышена до 1.0.0-beta.2.

Для первого запуска распакуйте и выполните:

```sh
./analyzer -t demo/vulnerable-app -report all -sarif
```

Windows PowerShell: используйте `./analyzer.exe`. Откройте `analysis_output/REPORT.html`.
