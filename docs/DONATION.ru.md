# Поддержать проект

[English](DONATION.md)

Текущая версия Mega-Analyzer **бесплатна для использования** под
[BSD-3-Clause](../LICENSE) ИЛИ [GPLv2](../COPYING), на ваш выбор. Донаты добровольны.

Новые крупные версии будут платными. Скачанной бесплатной версией можно продолжать
пользоваться без покупки обновления. [Условия обновлений](SUPPORT.ru.md#версии-и-обновления).

## Зачем донатить?

Если Mega-Analyzer сэкономил тебе время или чему-то научил, донаты помогают:

- Оплачивать CI/CD-инфраструктуру для сборки
- Оплачивать вычисления для обучения офлайн-моделей GNN/HDC
- Поддерживать разработку и сопровождение проекта

## Как поддержать

- **DonationAlerts** → [donationalerts.com/r/promastergame](https://www.donationalerts.com/r/promastergame)

Для заказа функции, интеграции или другой разработки сначала обсудите задачу
с автором: [доработки на заказ](SUPPORT.ru.md#доработки-на-заказ).
Донат сам по себе не покупает платную версию, не оплачивает конкретную работу
и не устанавливает срок её выполнения.
