[English](COMPARISON.md)

## Где Mega-Analyzer идёт дальше

1. **Smali-level анализ приватности и трекинга** — не просто "опасный API", а полный data-flow: где собираются пользовательские данные, куда они идут, какие SDK-трекеры их касаются, с маппингом на реальные пути кода в Smali.
2. **Глубже нативный + JAR анализ** — OmniSec (Rust) строит полный CFG/SSA/PDG для PE, ELF, Mach-O и DEX с межпроцедурным taint, отслеживающим потоки из Java через JNI в нативный код и обратно. MobSF этого не делает.
3. **Браузер артефактов** — картинки, видео, 3D-ассеты, аудио и raw-пейлоады из APK извлекаются и показываются в HTML-отчёте. Удобно для поиска пасхалок, скрытых пейлоадов и стеганографии.
4. **Намного меньше весит** — один бинарник ~60 МБ против Docker-образа MobSF (~500 МБ+). Без Python, Django и скриптов настройки.
5. **Выбор лицензии** — Mega-Analyzer поддерживается Promaster и распространяется под [BSD-3-Clause](../LICENSE) ИЛИ [GPLv2](../COPYING), на ваш выбор.
6. **Не нужен Docker** — скачал, запустил, готово. MobSF требует Docker или полное Python-окружение.
7. **Стек Go + Rust + Elixir** (Zig для GUI песочницы) — без Python, без JVM на горячих путях. Старт мгновенный, память предсказуемая.
8. **Ручной патчер с CFG-осведомлённостью** — Mega-Analyzer находит точки патча и генерирует Smali-диф; *ты* решаешь что применять. Автоматический патчинг без ревью — это footgun.

## Где MobSF выигрывает

- Более устоявшийся веб-UI и интеграции с третьими сторонами
- Больше сообщество и контрибьюторов
- Некоторые динамические фичи более зрелые
