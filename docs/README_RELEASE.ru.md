# Mega-Analyzer — Выпуск (Релиз)

Этот архив содержит предварительно скомпилированные исполняемые файлы и библиотеки Mega-Analyzer.

## 📁 Содержимое архива

- **`analyzer` / `analyzer.exe`**: Основной движок Go CLI.
- **`*.dll` / `*.so`**: Библиотеки нативных движков (символьное выполнение OmniSec, среда выполнения GNN, лифтеры).
- **`elixir_server/`** (если включен): Предварительно скомпилированный приватный сервер Elixir/OTP.
- **`QUICKSTART.md`**: Краткое руководство по быстрому старту.
- **`FlagiFiles.md`**: Полный справочник всех параметров командной строки.

## 🚀 Как запускать

Базовый анализ через консоль:
```bash
./analyzer -t <путь_к_apk_или_бинарнику>
```

Запуск веб-интерфейса в браузере:
```bash
./analyzer -web
```

Интерактивный мастер в терминале:
```bash
./analyzer -tui -t <путь_к_apk_или_бинарнику>
```

## ⚙️ Использование нативных движков

> [!IMPORTANT]
> Основной исполняемый файл `analyzer` / `analyzer.exe` **не запустится** без файлов нативных библиотек (`*.dll` / `*.so`), расположенных в той же папке. Убедитесь, что они находятся рядом с исполняемым файлом.

- В Windows: Автоматически подгружаются, если лежат в одной папке с `analyzer.exe`.
- В Linux: Убедитесь, что библиотеки находятся в одной папке с бинарником `analyzer`, и запускайте так:
  ```bash
  LD_LIBRARY_PATH=. ./analyzer -t <путь_к_apk_или_бинарнику>
  ```

## 🌐 Приватный сервер Elixir (Опционально)

Если ваша сборка включает `elixir_server/`, вы можете запустить его для распределенного анализа:
- Запустите сервер:
  ```bash
  ./elixir_server/bin/omnisec_server start
  ```
- Настройте клиент `analyzer` для подключения к серверу:
  ```bash
  ./analyzer -t <путь_к_apk_или_бинарнику> -sandbox-privserver 127.0.0.1:9339
  ```
