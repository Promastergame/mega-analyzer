# Support

[Русский](SUPPORT.ru.md)

## Versions and upgrades

The current public Mega-Analyzer version is free to use locally under
[LICENSE](../LICENSE). New major versions will be sold as separate paid upgrades.
Their contents, prices and purchasing instructions will be published in the
corresponding release announcement.

Buying an upgrade is optional. A paid release does not require payment for a
previously downloaded free version: you can keep using it under its license.

## Getting help

- **Docs** → [README](../README.md) · [FAQ.md](FAQ.md) · [USAGE.md](USAGE.md)
- **Bug or unexpected behavior** → [open an issue](https://github.com/Promastergame/mega-analyzer/issues/new?template=bug_report.yml)
- **Feature request** → [open an issue](https://github.com/Promastergame/mega-analyzer/issues/new?template=suggestion.yml)
- **Security vulnerability** → [private advisory](https://github.com/Promastergame/mega-analyzer/security/advisories/new)

Bug reports and suggestions are welcome free of charge. This is a solo-maintained
project, so response times for these requests are not guaranteed.

## Custom development

**[Contact the author about a task](https://github.com/Promastergame/mega-analyzer/issues/new?template=custom_work.yml)**

Custom work inquiries currently use GitHub. The form is public: a brief description
without confidential materials or credentials is enough for the first message.

You can commission a new Mega-Analyzer feature, an integration, automation or a
standalone utility. Describe the task, expected result, operating system and,
if relevant, your preferred deadline. Details can be discussed in writing.

The author first assesses feasibility, then agrees on the scope, price, schedule
and acceptance criteria with you. Work is accepted once the terms are agreed.

A donation is voluntary support for the project. Upgrades and commissioned work
are purchased separately; a DonationAlerts payment alone does not purchase a
version or place an order.
