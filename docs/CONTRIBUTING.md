# Contributing

[Русский](CONTRIBUTING.ru.md)

Mega-Analyzer is a **solo-maintained project** — pull requests are not accepted.

## What you can do

- **Bug report** → [open an issue](https://github.com/Promastergame/mega-analyzer/issues/new?template=bug_report.yml)
- **Feature idea** → [open an issue](https://github.com/Promastergame/mega-analyzer/issues/new?template=suggestion.yml)
- **Security vulnerability** → [private advisory](https://github.com/Promastergame/mega-analyzer/security/advisories/new) — never a public issue
- **Support the project** → [DONATION.md](DONATION.md)

## Why no PRs?

Keeping the codebase under a single author's control is a deliberate choice — it keeps the architecture coherent and the security surface auditable. A well-written issue is genuinely valuable and will be read.
