# Переработка Smart Patcher + APK Editor

[English](SMART_PATCHER_OVERHAUL.md)

## Находки аудита

- Ключи поиска патчей использовали только `file_path + method_name`, поэтому перегруженные методы могли затирать или дедуплицировать друг друга.
- Go-экспортёр уже выдавал хеши и блочные артефакты, но Zig APK Editor их игнорировал.
- Редактор заменял тело метода целиком даже там, где существовал минимальный валидированный блочный патч.
- Откат одного патча восстанавливал весь файл `.original`, потенциально снося несвязанные правки и другие патчи.
- Сопоставление методов принимало вольные подстроки и молча выбирало первое совпадение.
- Пути патчей склеивались без отсечения абсолютных путей и обхода через `..`.
- `apply_safe` экспортировался, но IDE его не соблюдала.
- JSON-персистентность в IDE подставляла исходный код без экранирования JSON.
- Отдельная команда `cmd/patch-apk` содержала захардкоженные пути разработчика.

## Совместимость

Редактор по-прежнему читает legacy-файлы патчей `1.0.0`. Новые экспорты используют схему `2.0.0` и добавляют опциональные поля; старые потребители могут их игнорировать. Исходный `patches.json` остаётся совместимым с существующим воркфлоу очереди/истории.
