## Что это значит для выбора стратегий

Для 26 native-деклараций Smali-патчер видит интерфейс, но не реализацию в DEX. Среди примеров есть `Cocos2dxRenderer.nativeRender`, `Cocos2dxRenderer.nativeOnResume`, `MainActivity.onControllerKeyEvent`. Native/abstract нельзя выдавать за обычные Java/Smali-методы с переписываемым телом. Новые общие admission-проверки призваны исключить такой класс ложных предложений; **их Go-исполнение на этом APK не проводилось**.

В DEX присутствуют многочисленные support/ad SDK-классы. Следовательно, общее число найденных методов или сигналов не измеряет качество стратегий для кода игры. Для следующего полноценного сравнения нужен учёт принадлежности к приложению/SDK/native, сценарные метки, фактическая сборка, выполнение и регрессии. Нельзя обучать модель так, будто каждый статически сгенерированный патч уже дал успешный результат.

## Границы выполненной работы

Исполнен отдельный Python-инвентаризатор таблиц DEX; он не вызывает Go-анализатор, не измеряет precision/recall и не выполняет игру. Не запускались apktool rebuild, подпись пересобранного APK, Android/ART, обучение модели и игровые сценарии. Разбор DEX ограничен версиями 035/037/038/039/040 и нужными таблицами; это не полноценный декомпилятор и не verifier. Отображаемые имена native-методов в JSON не содержат полных дескрипторов перегрузок, зато у каждого сохранён DEX method index.
