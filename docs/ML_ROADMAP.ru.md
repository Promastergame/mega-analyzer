# ML Roadmap: Стратегия развития машинного обучения в Mega-Analyzer

[English](ML_ROADMAP.md)

Основная философия развития ML в Mega-Analyzer: **«Накапливаем опыт — делаем модели умнее с каждым запуском»**. Платформа ориентирована на полностью локальный, приватный и быстрый инференс (вывод моделей) без внешних облачных зависимостей.

---

## Текущее состояние (Что уже работает)

На данный момент в Mega-Analyzer интегрировано несколько уровней классификации и интеллектуального анализа:

| Модель / Метод | Применение | Технология / Язык | Особенности |
|---|---|---|---|
| **HDC Auto-naming** | ИИ-автонейминг функций/переменных | Rust (`omnisec-hdc`) + Zig SIMD | 2048-битные гипервекторы, оффлайн, <10 МБ ОЗУ, Jaccard parity. |
| **Random Forest** | Скоринг уязвимостей в коде | Go (чистая реализация) | Обучение на локальных фичах, взвешенный Fit, стабильные деревья. |
| **GBT (Gradient Boosted Trees)** | Выявление аномалий и малвари | Go (чистая реализация) | Логарифмическая функция потерь (Log-loss), ранняя остановка. |
| **GNN (Graph Neural Network)** | Анализ потоков управления CFG/PDG | Rust (`omnisec-ml-gnn`) | Спектральная классификация графов по 8 классам уязвимостей. |
| **Platt Calibration** | Калибровка вероятностей | Go | Преобразование сырых выходов классификаторов в честную уверенность. |
| **Explainable AI** | Объяснение находок | Go / HTML | SHAP-inspired локальный разбор важности признаков. |

## В разработке (Текущие задачи)

1. **Training Pipeline из `history.json`**:
   * Интеграция автоматического извлечения признаков и разметки на основе лога пользовательского фидбека (`~/.analyzer/history.json`).
   * Реализация многоуровневого обучения (hard labels от пользователя ➔ soft labels ➔ heuristic pseudo-labels).
2. **Keyword Relevance Scorer**:
   * Модель на базе Logistic Regression с L2 регуляризацией для динамической фильтрации ложноположительных срабатываний (False Positives) на основе контекстных токенов.
3. **Drift Monitor (Контроль устаревания моделей)**:
   * Отслеживание метрики PSI (Population Stability Index) и дивергенции Кульбака — Лейблера (KL) для выявления расхождений между обучающей выборкой и сканируемым кодом.
   * Автоматический алерт пользователя о необходимости переобучения модели (`-ml-stats`).

## Будущее (Roadmap)

### Этап 1: Conformal Prediction (Конформное прогнозирование)
* Внедрение гарантированной оценки интервалов неопределенности. Модель должна сообщать, когда она «не уверена» в вердикте, вместо выдачи ложно-высокой вероятности.

### Этап 2: Локальное дообучение (Incremental Learning)
* Поддержка частичного дообучения моделей на лету (PartialFit) прямо в процессе разметки ложных срабатываний в TUI или HTML-отчёте.

### Этап 3: Community Signatures
* Безопасный экспорт весов локальных моделей для обмена обезличенным опытом с другими разработчиками (без экспорта исходного анализируемого кода).
