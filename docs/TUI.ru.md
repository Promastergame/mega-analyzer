# TUI Mega Analyzer

Запуск обновлённого интерфейса:

```powershell
.\bin\analyzer.exe -tui
.\bin\analyzer.exe -tui -t "F:\PROJECTS\mega-analyzer\Button VPN(1).apk"
.\bin\analyzer.exe -tui-section analysis
.\bin\analyzer.exe -tui-search sarif
```

Основная команда запуска — `bin/analyzer.exe`. Firmware и Make-server находятся в разделе Toolkit как отдельные действия. Они не включаются вместе с обычными флагами анализа. Основной Start запускает анализ приложения; Firmware не принимает APK/DEX и другие пакеты приложений.

Главный экран содержит поле пути. Можно вставлять путь с пробелами, скобками, кириллицей и внешними кавычками. Буквы из имени файла не вызывают команды. Длинный путь прокручивается около курсора; отображаемое сокращение не меняет значение.

| Клавиши | Действие |
| --- | --- |
| Enter на главном экране | Запуск анализа |
| Tab на главном экране | Открыть настройки |
| Tab / Shift+Tab в настройках | Следующий / предыдущий раздел |
| 1–9 в настройках | Перейти к разделу |
| ↑ / ↓, PgUp / PgDn | Выбрать параметр |
| ← / → в настройках | Изменить переключатель, число или вариант |
| Enter в настройках | Изменить значение или выполнить действие |
| Ctrl+K | Поиск флагов и действий |
| Ctrl+S | Запустить анализ с текущими настройками |
| F1 | Справка |
| Esc | Отменить редактирование / вернуться домой |
| Ctrl+C | Выход с подтверждением |
| ← / →, Home / End при вводе | Переместить курсор |
| Backspace / Delete | Удалить символ до / после курсора |
| Ctrl+U при вводе | Очистить поле |
| Ctrl+W при вводе | Удалить предыдущее слово |
| Ctrl+P на главном экране | Результаты |

Настройки разделены на девять групп: основные параметры (`general`), анализ кода (`analysis`), мобильная безопасность (`mobile`), соответствие требованиям (`compliance`), артефакты (`artifacts`), данные и кэш (`cache`), отчёты и фильтрация (`reports`), инструменты (`toolkit`), сеть (`network`). На широком экране разделы находятся слева, параметры — справа. В небольшом окне используется одна колонка с прокруткой.

В TUI доступны дополнительные параметры байткода, data-flow и его лимитов, размеров кода и ресурсов, медиакриминалистики, экспорта артефактов, бюджета встраивания, content cache, путей OBB/data, временных файлов, SARIF, строгой фильтрации и подавленных находок. Под списком показаны CLI-имя и описание выбранного параметра. Поиск учитывает названия, описания, разделы и имена флагов, например `--data-flow-max-methods`. Выбор числового или текстового параметра в поиске переводит к нему в настройках; Enter открывает редактор.

`-tui-section NAME` и `-tui-search TEXT` включают TUI автоматически. Явный `-no-tui` имеет приоритет. Параметры, переданные через CLI, сохраняются при открытии интерфейса.
