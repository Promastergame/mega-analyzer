# -admin, локальный Web UI и UTF‑8

[English](WEB_ADMIN.md)

## Запуск

Из корня проекта с Go 1.27.3:

```bash
go build ./pkg/cmd/analyzer
```

Windows:

```powershell
.\analyzer.exe -web -admin
```

Linux / уже рутованный Android с подходящим бинарником:

```bash
./analyzer -web -admin
./analyzer -web -admin -web-port 8080
```

- `-admin` работает только с `-web`, не с отдельным REST API, CLI-детонацией или IDE-командой. Другие режимы отклоняются до запроса прав; параметры анализов выбираются в UI.
- Windows: штатный UAC, широкосимвольный запуск и повторная проверка токена процесса. Отмена UAC не скрывается.
- Linux: `sudo --user=root`; приложение не читает и не сохраняет пароль. Без sudo нужен уже повышенный терминал.
- Android: только уже рутованное устройство и разрешение root-менеджера с `su -c`. Это не рутование, обход SELinux или разблокировка загрузчика. Права Windows/Linux-хоста не выдают root телефону через ADB.
- Уже повышенный процесс не перезапускается. Неудачный дочерний запуск не создаёт цикл запросов прав. Рабочий каталог и Unicode-аргументы сохраняются.

## Локальный доступ

После подтверждения ОС консоль сервера покажет полную ссылку `http://127.0.0.1:7474/?t=…`. Открой её в обычном браузере. **Браузер намеренно не запускается от administrator/root.** Сервер останавливается через Ctrl+C в его консоли.

Привилегированный сервер допускает только буквальный loopback IP; localhost нормализуется без DNS. Нелокальное значение `MEGA_ANALYZER_HOST` запрещено. Обязателен случайный токен, даже на loopback; ошибка его генерации запрещает запуск. Токен создаётся в дочернем процессе, а не передаётся ему в аргументах. Сохраняются Host/Origin/Fetch-Site проверки и HttpOnly/SameSite=Strict cookie; Origin дополнительно проверяется по схеме, хосту и порту.

Профили `analyzer.flags*.txt` для явного `-admin` автоматически отключены. Профиль сам не может разрешить повышение. При использовании явного `-web-ui-token` нужны 32–256 случайных URL-safe ASCII символов. Такой явно введённый секрет может быть виден в списке процессов; лучше оставить автогенерацию.

**Это повышенные права, а не изоляция.** Анализы и дочерние инструменты могут получить права сервера. Для недоверенных образцов используй одноразовую VM/лабораторное устройство, не основную систему. Флаг не превращает синтетические сборщики в реальные драйверы.

## UTF‑8

- Windows-консоль переключается на CP_UTF8 (65001) через Win32 API, без shell/chcp. Нет консоли — безопасная пустая операция; ошибка переключения даёт предупреждение. Шрифт/терминал всё равно должен поддерживать символы.
- Go/HTTP/JSON остаются UTF‑8 без добавления BOM. Кодировки самих образцов, бинарных файлов и вывода сторонних утилит не переписываются.
- Файлы флагов принимают UTF‑8, включая начальный UTF‑8 BOM; UTF‑16/невалидный UTF‑8 отклоняется.
- Патчи — UTF‑8 без BOM. Контекстные окончания строк и binary hunks сохраняются ради применимости.

## Применение патча

**Выбери только один:**

- `Mega-Analyzer-full-admin-utf8.patch` — к исходному `Mega-Analyzer.zip`: предыдущий sandbox-v2, README и очистка плюс этот этап.
- `Mega-Analyzer-v2-admin-utf8.patch` — поверх ранее выданного `Mega-Analyzer-sandbox-v2.zip`: только этот этап.

Из корня соответствующего проекта, где находится go.mod:

```bash
git apply --check /path/to/Mega-Analyzer-v2-admin-utf8.patch
```

Только если проверка успешна:

```bash
git apply --whitespace=nowarn /path/to/Mega-Analyzer-v2-admin-utf8.patch
go build ./pkg/cmd/analyzer
```

Для исходного архива замени имя на полный патч. Git нужен, создавать репозиторий не обязательно. На Windows можно указать `.\Mega-Analyzer-v2-admin-utf8.patch`. Не пересохраняй файл в ANSI/UTF‑16 и не применяй оба патча подряд. Для вручную изменённых исходников сначала разреши несовпадения.

## Регрессионные проверки

```bash
go test ./pkg/cmd/analyzer ./pkg/cmd/analyzer/web
```

Новые тесты проверяют web-only флаг, запрет неявного повышения из профиля, отсутствие повторного повышения, Unicode/BOM, аргументы Windows/POSIX, буквальность shell-метасимволов, loopback, токен и Origin. Повышение в тестах подменяется: реальный UAC/sudo/su не запускается. Живой Windows/Android-прогон и права на конкретном устройстве требуют отдельной проверки. IDE и остальные исходные модули сохранены.
