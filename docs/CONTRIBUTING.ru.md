# Участие в проекте

[English](CONTRIBUTING.md)

Mega-Analyzer — **соло-проект**, pull request'ы не принимаются.

## Что можно сделать

- **Баг-репорт** → [открыть issue](https://github.com/Promastergame/mega-analyzer/issues/new?template=bug_report.yml)
- **Идея или предложение** → [открыть issue](https://github.com/Promastergame/mega-analyzer/issues/new?template=suggestion.yml)
- **Уязвимость безопасности** → [приватный advisory](https://github.com/Promastergame/mega-analyzer/security/advisories/new) — никогда не публичный issue
- **Поддержать проект** → [DONATION.md](DONATION.md)

## Почему не принимаются PR?

Держать кодовую базу под контролем одного автора — осознанный выбор: это сохраняет целостность архитектуры и делает поверхность безопасности аудируемой. Хорошо написанный issue реально ценен и будет прочитан.
