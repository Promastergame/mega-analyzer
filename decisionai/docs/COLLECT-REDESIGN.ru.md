# DecisionAI · Vision Studio

Обновление интерфейса `/collect` на основе приложенного vision-filter.zip.
Это не полный самостоятельный проект и не готовый EXE: исходный архив не содержал
`go.mod`, основной Handler, packages games/s1 и остальные файлы репозитория.

## Установка в существующий проект

1. Сохрани резервную копию репозитория.
2. Скопируй содержимое этой папки в корень полного репозитория DecisionAI,
   объединив папки `cmd`, `vision`, `docs`. Подтверди замену одноимённых файлов.
3. Главные изменения — cmd/dai/collect.html, collect.go, collect_test.go.
   Файлы пакета vision и прежние документы сохранены из исходного архива без изменений.
4. Из корня репозитория выполни:

```sh
gofmt -w cmd/dai/collect.go cmd/dai/collect_test.go
go test ./vision ./cmd/dai
go build -o .tmp/dai-vision.exe ./cmd/dai
```

Windows PowerShell:

```powershell
.\.tmp\dai-vision.exe serve -light
```

Открой http://127.0.0.1:7480/collect . Если путь сбора голосов в твоей сборке
не задан по умолчанию, используй существующий флаг `-collect-feedback`.
Расположение и порядок флагов сохраняются от исходного проекта.
Обязательно пересобери сервер: HTML встроен через go:embed.
Обновлять нужно и HTML, и Go-обработчик, иначе новые классы и счётчик не заработают.

## Что изменилось

- Новый адаптивный интерфейс, светлая/тёмная тема по системным настройкам.
- Режимы «Кровь», «Кожа», «Жидкости», «Все классы».
- Поле «Или напиши свой объект»: «кожа»/skin и «кровь»/blood переключают
  известные фильтры. Можно указать и отдельный код класса: blood_dark и т. п.
- Новый неизвестный объект создаёт режим РУЧНОЙ разметки, а не новый детектор.
  До 20 таких режимов сохраняются в localStorage текущего браузера.
- Рамки на изображении + отдельный список областей с «Да»/«Нет».
  На телефоне рамки подписаны номерами, названия видны в списке.
- Ручное выделение мышью/касанием или вводом координат с клавиатуры.
- Ошибка сохранения не удаляет выделение и не создаёт ложное подтверждение.
- 5 подтверждений на хеш изображения, включая ручные области; отклонения без лимита.
  Счётчик получает существующий бюджет с сервера при загрузке изображения.
- Сохранены Ctrl+V, drag-and-drop, автосжатие и существующий POST /v1/see.

## Серверный контракт

Добавлен GET /v1/collect/budget?sha=<64 hex> с тем же Bearer-токеном.
Ответ: {"likes":0,"max":5}. Читает существующий JSONL без его изменения.

POST /v1/collect/feedback дополнительно принимает box.class вида
`custom:Волосы`, только когда src = "hint". Название 1–64 Unicode-символа,
без управляющих знаков и пробелов по краям. Старые шесть классов не изменены.
Собственные классы не передаются в /v1/see и не меняют цветовые диапазоны.
Старые потребители JSONL должны учитывать новый префикс `custom:`.

## Ограничения

Фильтр остаётся цветовой эвристикой. Оценка 0–100 — не вероятность.
«Жидкости» — три прежних цветовых класса, не семантическое распознавание веществ.
Голоса сохраняются в JSONL, но автоматически не переобучают распознавание.
Разметка не восстанавливается из JSONL после перезагрузки страницы:
сервер возвращает только число уже использованных подтверждений.
Не используй фильтр для медицинских решений.

## Проверка

Проведены браузерные проверки Chromium с имитацией ответов API:
переключение режимов, текст «кожа», новые ручные классы, успешное и неуспешное
сохранение, сохранность выделения после ошибки, общий счётчик, выделение мышью,
проверка границ координат, безопасное отображение пользовательского текста,
localStorage, светлая/тёмная тема, ширина 390 px и отсутствие ошибок JavaScript.
Выполнен визуальный просмотр снимков и расчёт контраста основных пар текста/UI.

Go-тесты дополнены, но НЕ запускались: в среде нет Go и полного репозитория.
Реальное подключение к /v1/see и запись через Go-сервер в этой среде не проверялись.
После установки обязательно запусти команды проверки выше.
