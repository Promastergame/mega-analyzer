В DecisionAI внедрены загрузка модели навыков по требованию, кэш готовых оценок и ограничение памяти кэша векторов. Проверка выполнена 15.10.2026 на Windows amd64, Intel Core i5-3340, Go 1.27.1, с существующим ускорителем Nim+FASM.

Готовая нативная сборка: [bin/dai-native.exe](../bin/dai-native.exe); та же сборка установлена в `bin/dai.exe`. Прежний `bin/dai.exe` сохранён в `.tmp/perf-upgrade-20261015/bin-before/`. Отдельное имя `dai-native.exe` позволяет сохранить ускоренную версию при запуске скриптов, которые собирают обычный Go-вариант в `dai.exe`.

```powershell
.\bin\dai-native.exe serve
```

Обычный запуск `-backend s1` загружает модели A и B. `encoder-tiny.dte` загружается один раз при первом нерешённом запросе `task=skill_routing`. Старые пользовательские DTE без собственной таблицы слов по-прежнему получают базовую модель при запуске. Ошибки загрузки возвращаются вызывающему коду. Отмена одного ожидающего запроса не прерывает общую загрузку для остальных. Добавление модели в реестр Nim синхронизировано с текущими вычислениями.

Кэш готовых `Judgement` расположен над ансамблем и отдельно над моделью навыков. Он сохраняет значения для пары текстов, поэтому повторный запрос пропускает сравнение токенов и расчёт признаков. По умолчанию выделено 2 МиБ на такой кэш. Ключ — SHA-256 с длинами обоих текстов; исходные тексты в кэше оценок не удерживаются. Повторяющиеся пары внутри одного пакета вычисляются один раз. Ошибочные, отменённые и неполные результаты не добавляются в кэш.

Кэш векторов ограничен 16 МиБ на модель: 32 МиБ для A+B и ещё до 16 МиБ после включения модели навыков. Старые записи вытесняются по давности использования, без массовой очистки. Слишком большие записи не сохраняются. Учитываются массивы, ключи и запас на служебные структуры; это бюджет кэша, а не ограничение всей RAM процесса. Веса, рабочие буферы, нативная память и резерв Go учитываются отдельно.

**Измерения настоящего CLI-движка.** Оба измерителя вызывают `buildEngine` и стандартный `loadExperts`, используют одни и те же сохранённые веса и [support.json](../examples/s1/support.json) с тремя вопросами. Эксперты и обе модели ансамбля включены. Для коротких серий выполнены три отдельных запуска каждого варианта; ниже медианы трёх запусков. **Качество и проверки.** На семи наборах CI, всего 719 вопросов, отчёты совпали полностью после исключения времени: 584 правильных ответа в каждом варианте, ошибок выполнения нет. На трёх наборах выбора навыков — 110 случаев, 105 правильных — отчёты также совпали, включая планы и калибровочные метрики. Все три порога выбора навыков проходят.
