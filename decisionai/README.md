# v1: патч памяти 03 — накопительный

Кодировка: UTF-8 с BOM, строки CRLF. README-EN.txt — английская ASCII-копия.

## Изменения

1. Nim+FASM упаковывает линейные матрицы прямо из входного буфера,
   без дополнительной исходной Nim-копии. Удаляемые массивы:
   9 165 312 байт (8,74 MiB) на энкодер этой архитектуры.
   Указатель Go не сохраняется. Обычный путь без FASM остаётся.
2. Побитово одинаковые таблицы токенов и масштабы используют общие массивы.
   У s1-distilled и s1-distilled-b они совпадают; у encoder-tiny отличаются.
3. НОВОЕ: одинаковый токенизатор используется один раз даже при разных весах
   таблиц. Это убирает лишнюю карту словаря, список токенов и строки.
   Проверяются размер, полный словарь с порядком токенов и режим lower.
   Сравнение не создаёт дополнительную склеенную строку словаря.

Веса, Transformer-слои, состав ансамбля и алгоритм ответов не изменены.
Глобального кэша нет. Общие структуры неизменяемы во время inference.
Go-изменения относятся к загрузчику; основной native forward — Nim+FASM.
Новых весов нет; старые метаданные учителей остаются прежними.

## Установка — Windows, без WSL

Сохранить старые nim\dainim.nim и semai\encoder.go.
Распаковать этот архив в корень проекта с заменой файлов.
Патчи 01 и 02 уже включены: отдельно их накладывать не нужно.
В PowerShell из корня проекта:

```powershell
python tests\check_pack.py models\encoder-tiny.dte
go test ./semai -run '(WordShare|TokenizerShare)' -count=1 -v
Remove-Item Env:DAI_NO_FASM -ErrorAction SilentlyContinue
.\BUILD-NIM-WINDOWS.cmd
```

Nim, Go и MinGW должны быть в PATH согласно штатному скрипту сборки.
Скрипт запускает NimParity. При ошибке не использовать новый бинарник.
Откат: вернуть оба исходных файла и пересобрать.

## Измерения

После загрузки encoder-tiny, s1-distilled и s1-distilled-b и runtime.GC,
прирост живой Go-кучи относительно замера перед загрузкой:

- Исходный загрузчик (прошлый замер): 127 541 224 байт.
- Патч 02, контрольный замер этого шага: 94 967 168 байт.
- Патч 03: 88 873 352 байт.

Новый шаг убрал около 6,09 МБ; относительно исходного замера — около 30,3%.
Один контрольный прогон на вариант. Это НЕ полная RAM процесса, НЕ RSS,
и НЕ замер Nim+FASM. Колебания Go-кучи между прогонами возможны.
Размер устранённых Nim-массивов не прибавляется к этим цифрам как к RSS.
Повторить: go run ./tools/memprobe

## Проверки

- Упаковка 18 матриц: побитово совпадает, Python stdlib.
- Совпадающие токенизаторы/таблицы разделяются; различающиеся — нет.
- Проверены отличия словаря, его длины и порядка содержимого,
  весов, масштабов, lower, hidden; префикс и лишний перевод строки.
- Transformer-слои остаются независимыми.
- На двух текстах для каждой из двух реальных пар моделей токены,
  Mean/Tokens выходы совпали с отдельной загрузкой в эталонном Go-пути.
- go test ./... прошёл. Логи находятся в checks/.

НЕ проверены: компиляция изменённого Nim, native forward-паритет,
Windows-сборка, полная RAM, tok/s, p50, ECE и все 16 клеток качества.
Nim отсутствовал; предыдущая загрузка компилятора вернула HTTP 403.
Старые distilled-веса с запрещёнными учителями использованы только
для механических регрессионных проверок, не для нового обучения.
