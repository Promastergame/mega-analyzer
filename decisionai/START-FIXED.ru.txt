DecisionAI — исправления 16.10.2026

Полный архив распаковать в новую папку. Сохранить исходную версию.
Для Windows: RUN-DAI.cmd serve
Затем: http://127.0.0.1:7480/playground или /collect или /games.

Включён Windows amd64 Go-бинарник. Он кросс-компилирован; Windows runtime
в этой среде не проверялся. На Linux проверены Go и Nim+FASM.

Для быстрой Windows-сборки: BUILD-NIM-WINDOWS.cmd
Требуются Go 1.22+, Nim 2.2.x, MinGW, CPU с AVX.
Для пересборки без Nim: BUILD-S1.cmd
Не запускать старый bin/dai.exe в расчёте получить новые исправления.

Веса НЕ менялись. Старые калибровки не дают нейросетям route=auto, пока
не выполнена новая калибровка для той же конфигурации. Это намеренная защита.
