Команды управления и CLI

Управление сервисом (PowerShell 7)

Помощник запускает фоновый процесс на loopback и сохраняет токен под защитой Windows DPAPI:

# Запуск службы DecisionAI
.\scripts\decision-ai.ps1 -Action Start

# Статус и параметры работы
.\scripts\decision-ai.ps1 -Action Status

# Остановка службы
.\scripts\decision-ai.ps1 -Action Stop

Статический анализ с ИИ-ассистентом

Подключение DecisionAI к Mega-Analyzer для разбора находок и размытия картинок:

# Запуск веб-интерфейса Mega-Analyzer с DecisionAI
.\bin\analyzer-decisionai.exe -web -decision-ai-url http://127.0.0.1:7480

# Прямое сканирование APK с триажем находок
.\scripts\decision-ai.ps1 -Action Scan -Target 'sample.apk'
