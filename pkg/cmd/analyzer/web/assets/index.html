VMware · запуск в гостевой Windows

Анализатор включит выбранную ВМ, передаст файл через VMware Tools и сохранит отчёт на основном ПК. После сеанса гостевая Windows будет выключена.

Подготовка отключает сеть, общие папки, буфер обмена, перетаскивание и USB. Исходный VMX сохраняется рядом с ВМ.

Выберите проверку. Она не запускает Windows и не передаёт файлы.
Проверка конфигурации

    Для видимого запуска после включения ВМ откройте Screen и войдите на рабочий стол под указанной ниже учётной записью. Ожидание входа — до 90 секунд; затем запуск отменяется. Файл передаётся через VMware Tools; общие папки и буфер обмена остаются выключенными.

    Имя и пароль должны относиться к одной учётной записи гостевой Windows. VMware не принимает пустой пароль. Можно загрузить файл guest-login.json, созданный при настройке тестовой учётки. Данные используются только для текущего запуска; в госте нужны VMware Tools.
    Операции разрешены только при выключенной ВМ. Восстановление удалит изменения после снимка. Снимок не является защитой основного ПК.
    Native Windows execution runs on the analyzer host, NOT in a VM. Filesystem access is not isolated; firewall rules cover the launched executable, not its descendants. User-mode limits cannot contain kernel exploits or drivers — a crashing sample can bluescreen this PC. Never use your everyday PC for unknown samples.
    Monitoring depth
    Basic: observed processes, sockets, workspace / autorun differences. Trace, kernel capture, time-warp and VSS rollback are unavailable; no generated evidence is used.
